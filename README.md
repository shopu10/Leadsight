A data analytics and machine learning pipeline investigating childhood lead-exposure risk factors in Bangladesh using UNICEF MICS survey data.
- [x] Dataset preparation & variable inventory
- [ ] Data cleaning & missing-value handling
- [ ] Exploratory Data Analysis (EDA)
- [ ] Feature engineering & selection
- [ ] Machine learning modeling & comparative evaluation
- [ ] Interactive risk intelligence dashboard
Original MICS `.sav` files (`CH.sav`, `HH.sav`, `BH.sav`) and individual-level child/household `.csv` datasets are **excluded** from this repository via `.gitignore` to respect survey data-sharing terms and participant privacy. This repository contains only project code, documentation, and safe aggregated results.

To reproduce the pipeline locally, obtain authorized MICS survey files from [mics.unicef.org](https://mics.unicef.org) and place them inside a local `data/` directory (ignored by Git).
